| Original Variable | Representation in the Tree | Recommended Clean Name |
| :---------------- | :------------------------- | :--------------------- |
| `p`                | The immediate parent node  | `parent`               |
| `pp`               | The grandparent node       | `grandparent`          |
| `u`                | The first node or element  | `node_a` (or `node`)   |
| `v`                | The second node or element | `node_b` (or `target`) |
| `z`                | A transient lookahead node | `next_parent`          |
| `_u`, `_v`         | Input arguments/aliases    | `input_a`, `input_b`   |
